用纯 HTML + CSS + GitHub Pages 搭起这个网站

你现在看到的这个网站，没有用任何框架，没有 npm，没有构建工具，就是几个 HTML 文件加一份 700 多行的 CSS，托管在 GitHub Pages 上。写这篇文章记录一下搭建过程和取舍。

为什么不用现成的博客框架

Hugo、Hexo、Jekyll 都很好，但对一个想彻底搞懂网页基础的人来说，它们把太多事情藏起来了。手写 HTML + CSS 的好处是：页面上的每一个像素、每一个交互都是自己写出来的，以后学 Vue 或 React 时，也更容易理解框架到底替你做了什么。

几个设计决策

CSS 变量做主题系统。所有颜色定义成 :root 变量，暗色模式只需要在 body.dark 下覆盖同一组变量，切换主题不用重新渲染任何东西。

粘性导航 + 毛玻璃。header 用 position: sticky 加 backdrop-filter，滚动时内容从半透明导航下面穿过，观感立刻上一个档次。

卡片式布局。项目卡片和文章卡片复用同一套 .post-card 样式，hover 时 translateY(-2px) 加阴影加深，配合 fadeInUp 入场动画。

暗色模式的实现

核心逻辑不到十行 JavaScript：点击按钮切换 body 的 dark 类，用 localStorage 记住选择，页面加载时先读取。因为所有颜色都走变量，切类就是切主题。

部署

仓库改名为 renaissance-debu.github.io 之后，GitHub Pages 会自动把 main 分支的 index.html 发布到 https://renaissance-debu.github.io，git push 即部署，零配置。

静态网站是理解 Web 的最好起点：HTML 管结构，CSS 管表现，JavaScript 管行为，DNS 和 HTTP 在幕后工作。这些概念在框架时代依然天天用到。

接下来打算给网站加文章的代码高亮和 RSS，也许再把项目卡片做成数据驱动渲染。慢慢来。
